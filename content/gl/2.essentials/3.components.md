As compoñentes de Markdown son substitutos das etiquetas de tipografía HTML. Ofrecen unha forma sinxela de personalizar a interface ao usar Markdown.

**Docus e Nuxt UI** proporcionan un conxunto de compoñentes de Markdown elegantes e con estilo para axudarche a escribir a túa documentación coa [sintaxe MDC](https://content.nuxt.com/docs/files/markdown#mdc-syntax).

::note{to="https://ui.nuxt.com/getting-started"}
Esta páxina só destaca as compoñentes de Markdown máis axeitados para escribir documentación. Non obstante, podes usar **calquera compoñente da IU de Nuxt** no teu Markdown. Para obter unha lista completa das compoñentes dispoñibles, consulta a documentación de Nuxt IU.
::

### `Callout`

Usa Markdown no espazo predeterminado do compoñente `callout` para engadir contexto visual ao teu contido.

Usa os accesorios `icon` e `color` para personalizalo. Tamén podes pasar calquera propiedade do compoñente `<NuxtLink>`.

Tamén podes usar os atallos `note`, `tip`, `warning` e `caution` con iconas e cores predefinidas.

::tabs
  :::tabs-item{.my-5 icon="i-lucide-eye" label="Vista previa"}
    ::::div{.flex.flex-col.gap-4.w-full}
      :::::note{.w-full.my-0}
      Aquí tes información adicional.
      :::::

      :::::tip{.w-full.my-0}
      Aquí tes unha suxestión útil.
      :::::

      :::::warning{.w-full.my-0}
      Ten coidado con esta acción xa que podería ter resultados inesperados.
      :::::

      :::::caution{.w-full.my-0}
      Esta acción é irreversible.
      :::::
    ::::
  :::

  :::tabs-item{icon="i-lucide-code" label="Code"}
  ```mdc
  ::note
  Aquí tes información adicional.
  ::

  ::tip
  Aquí tes unha suxestión útil.
  ::

  ::warning
  Ten coidado con esta acción xa que podería ter resultados inesperados.
  ::

  ::caution
  Esta acción é irreversible.
  ::
  ```
  :::

### `Card` e `CardGroup`

Usa Markdown na ranura predeterminada do compoñente `card` para destacar o teu contido.

Usa os elementos `title`, `icon` e `color` para personalizalo. Tamén podes pasar calquera propiedade do compoñente `<NuxtLink>`.

Agrupa os teus compoñentes `card` co compoñente `card-group` para mostralos nunha grella.

      :::::card
      ---
      icon: i-simple-icons-github
      target: _blank
      title: Panel de control
      to: https://github.com/nuxt-ui-templates/dashboard
      ---
      Un panel de control cun deseño de varias columnas.
      :::::

      :::::card
      ---
      icon: i-simple-icons-github
      target: _blank
      title: SaaS
      to: https://github.com/nuxt-ui-templates/saas

      :::::card
      ---
      icon: i-simple-icons-github

### `Collapsible`

Envolve o teu contido co compoñente `collapsible` para mostrar un elemento [Colapsable](https://ui.nuxt.com/components/collapsible) no teu contido.

::tabs
  :::tabs-item{.my-5 icon="i-lucide-eye" label="Vista previa"}
    ::::collapsible
    | Correcto | Predeterminado | Tipo |
    | --------- | ---------  | -------- |
    | `name`    |            | `string` |
    | `size`    | `md`       | `string` |
    | `color`   | `neutral`  | `string` |
    ::::
  :::

  :::tabs-item{icon="i-lucide-code" label="Code"}
  ```mdc
  ::collapsible

  | Correcto | Predeterminado | Tipo               |
  |----------|-----------------|--------------------|
  | `name`  |           | `string`{lang="ts-type"}  |
  | `size`  | `md`      | `string`{lang="ts-type"}  |
  | `color` | `neutral` | `string`{lang="ts-type"}  |

  ::
  ```
  :::

### `Field` e `FieldGroup`

Un `field` é un elemento ou parámetro que se mostra no teu contido. Podes agrupalos usando `field-group` para crear unha lista.

::tabs
  :::tabs-item{.my-5 icon="i-lucide-eye" label="Vista previa"}
    ::::field-group{.my-0}
      :::::field{name="analytics" type="boolean"}
      Definido como `false` por defecto - Activar a analítica para o teu proxecto (próximamente).
      :::::

      :::::field{name="blob" type="boolean"}
      Definido por defecto como `false` - Activa o almacenamento de blobs para almacenar recursos estáticos, como imaxes, vídeos e moito máis.
      :::::

      :::::field{name="cache" type="boolean"}
      Definido por defecto como `false` - Activa o almacenamento en caché para almacenar as respostas das rutas ou funcións do servidor con `cachedEventHandler` e `cachedFunction` de Nitro.
      :::::

      :::::field{name="database" type="boolean"}
      Definido por defecto como `false` - Activa a base de datos SQL para almacenar os datos da aplicación.
      :::::
    ::::
  :::

  :::tabs-item{icon="i-lucide-code" label="Code"}
  ```mdc
  ::field-group
    ::field{name="analytics" type="boolean"}
      Definido por defecto como `false` - Activa a analítica para o teu proxecto (próximamente).
    ::

  ::field{name="blob" type="boolean"}
    Definido por defecto como `false` - Permite o almacenamento de blobs para almacenar recursos estáticos, como imaxes, vídeos e moito máis.
  ::

  ::field{name="cache" type="boolean"}
    Definido por defecto como `false` - Activa o almacenamento en caché para almacenar as respostas das rutas ou funcións do servidor con `cachedEventHandler` e `cachedFunction` de Nitro.
  ::

  ::field{name="database" type="boolean"}
    Definido por defecto como `false` - Activa a base de datos SQL para almacenar os datos da aplicación.
  ::
  ::
  ```
  :::

### `Steps`

Envolve os teus títulos co compoñente Steps para mostrar unha lista de pasos.

Usa a propiedade `level` para definir que título se usará para os pasos.

::tabs
  :::tabs-item{.my-5 icon="i-lucide-eye" label="Vista previa"}
    ::::steps{level="4"}
    #### Comezando un novo proxecto
    
    ```bash [Terminal]
    npm create nuxt@latest -- -t github:nuxt-content/docus
    ```
    
    #### Inicia a CLI de Docus para iniciar o teu servidor de desenvolvemento
    
    ```bash [Terminal]
    docus dev
    ```
    ::::
  :::

  :::tabs-item{icon="i-lucide-code" label="Code"}
  ````mdc
  ::steps{level="4"}
    #### Comezando un novo proxecto
    
    ```bash [Terminal]
    npm create nuxt@latest -- -t github:nuxt-content/docus
    ```
    
    #### Inicia a CLI de Docus para iniciar o teu servidor de desenvolvemento
    
    ```bash [Terminal]
    docus dev
    ```
  ::
  ````
