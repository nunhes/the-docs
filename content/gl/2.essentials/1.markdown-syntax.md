## Títulos

Utiliza títulos para presentar as seccións principais. Estes estruturan a túa documentación e axudan aos usuarios a navegar polo contido.

::code-preview
---
class: "[&>div]:*:my-0"
---
## Títulos

#code
```mdc
## Títulos
```
::

### Subtítulos

Usa subtítulos para dividir aínda máis as seccións. Crean unha xerarquía de contido máis detallada para unha mellor lexibilidade.

::code-preview
---
class: "[&>div]:*:my-0"
---
### Subtítulos

#code
```mdc
### Subtítulos
```
::

::tip
Cada título e subtítulo crea unha áncora e aparece automaticamente na táboa de contidos.
::

## Formato de texto

Docus admite a maioría das opcións de formato de Markdown.

| Estilo    | Sintaxe      | Resultado   |
| -------- | ------------ | ---------- |
| Negriñas     | `**negriñas**`   | **Negriña**   |
| Itálicas | `*itálicas*` | *Itálica* |
| Riscado    | `~~barré~~`  | ~~Riscado~~  |

Combina estilos para enriquecer o texto e destacar elementos.

| Estilo         | Sintaxe               | Resultado            |
| -------------- | --------------------- | ------------------- |
| Negriñas itálicas  | `**_Negriñas_**` | ***Negriñas itálicas*** |
| Negriñas riscado     | `~~**Negriñas**~~`        | ~~**Negriñas**~~        |
| Itálicas riscado | `~~*Itálicas*~~`      | ~~*Itálicas*~~      |

## Ligazóns

As ligazóns conectan diferentes partes da túa documentación e recursos externos, que son esenciais para a navegación e as referencias. Para crear unha ligazón, inclúa o texto da ligazón entre corchetes `[]()`.

::code-preview
---
class: "[&>div]:*:my-0"
---
[Nuxt UI](https://ui.nuxt.com/getting-started/installation/nuxt)

#code
```mdc
[Nuxt UI](https://ui.nuxt.com/getting-started/installation/nuxt)
```
::

### Ligazóns internas

Para enlazar páxinas na túa documentación, usa rutas relativas á raíz como `/getting-started/installation`.

::code-preview
---
class: "[&>div]:*:my-0"
---
[Installation](/gl/getting-started/installation)

#code
```mdc
[Instalación](/gl/getting-started/installation)
```
::

## Listas

Organiza elementos relacionados nun formato estruturado e lexible. Markdown admite listas non ordenadas, ordenadas e aniñadas para diversas necesidades.

### Sen ordenar

Usa listas sen ordenar para elementos sen unha orde específica. Comeza cada elemento cun símbolo `-`.

::code-preview
---
class: "[&>div]:*:my-0"
---
- Son un elemento da lista.
- Son outro elemento da lista.
- Son o último elemento da lista.

#code
```mdc
- Son un elemento da lista.
- Son outro elemento da lista.
- Son o último elemento da lista.
```
::

### Ordenadas

Utiliza listas ordenadas cando a orde dos elementos sexa importante, como os pasos dun proceso. Comeza cada elemento cun número.

::code-preview
---
class: "[&>div]:*:my-0"
---
1. Son un elemento da lista.
2. Son outro elemento da lista.
3. Son o último elemento da lista.

#code
```mdc
1. Son un elemento da lista.
2. Son outro elemento da lista.
3. Son o último elemento da lista.
```
::

### Aniñado

Crea listas xerárquicas con subelementos para estruturas complexas. Indentar os subelementos en catro espazos para aniñar.

::code-preview
---
class: "[&>div]:*:my-0"
---
- Son un elemento da lista.
  - Son un elemento da lista aniñado.
  - Son outro elemento da lista aniñado.
- Son outro elemento da lista.

#code
```mdc
- Son un elemento da lista.
  - Son un elemento da lista aniñado.
  - Son outro elemento da lista aniñado.
- Son outro elemento da lista.
```
::

## Táboas

Presentan datos estruturados en filas e columnas. As táboas son ideais para comparar datos ou enumerar propiedades.

::code-preview
---
class: "[&>div]:*:my-0 [&>div]:*:w-full"
---
| Correcto | Predeterminado | Tipo    |
| ------- | --------- | -------- |
| `name`  |           | `string` |
| `size`  | `md`      | `string` |
| `color` | `neutral` | `string` |

#code
```mdc
| Correcto | Predeterminado | Tipo               |
|---------|-----------|--------------------------|
| `name`  |           | `string`{lang="ts-type"} |
| `size`  | `md`      | `string`{lang="ts-type"} |
| `color` | `neutral` | `string`{lang="ts-type"} |
```
::

## Citas

Destaca citas, referencias ou textos importantes. As citas distinguen visualmente o contido citado.

### Unha liña

As citas dunha soa liña son ideais para citas curtas e impactantes. Engade un ">" ao comezo dun parágrafo. Ideal para citas curtas.

::code-preview
---
class: "[&>div]:*:my-0"
---
> Nuxt UI é unha colección de compoñentes, elementos componíbeis e utilidades de Vue baseados en Nuxt UI, orientados á estrutura e ao deseño e deseñados como bloques de construción para a túa aplicación.

#code
```mdc
> Nuxt UI é unha colección de compoñentes, elementos componíbeis e utilidades de Vue baseados en Nuxt UI, orientados á estrutura e ao deseño e deseñados como bloques de construción para a túa aplicación.
```
::

### Multiliña

As citas multiliña son axeitadas para citas longas ou para incluír varios parágrafos dentro dunha única cita.

::code-preview
---
class: "[&>div]:*:my-0"
---
> Nuxt UI é unha colección de compoñentes, elementos componíbeis e utilidades de Vue baseados en Nuxt UI, orientados á estrutura e ao deseño e deseñados como bloques de construción para a túa aplicación.
>
> Crea aplicacións Vue fermosas, adaptables e accesibles con Nuxt UI.

#code
```mdc
> Nuxt UI é unha colección de compoñentes, elementos componíbeis e utilidades de Vue baseados en Nuxt UI, orientados á estrutura e ao deseño e deseñados como bloques de construción para a túa aplicación.
>
> Crea aplicacións Vue fermosas, adaptables e accesibles con Nuxt UI.
```
::
