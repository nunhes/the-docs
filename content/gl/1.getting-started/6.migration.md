## **Migración de Docus v3 cara a v4**

Docus v4 introduce unha nova versión que usa a CLI de Nuxt en lugar da CLI de Docus. O contido e as configuracións existentes seguen sendo compatibles; só precisa actualizar o comando para iniciar o servidor ou a compilación.

### ⚠ Cambios importantes

Os principais cambios importantes están relacionados cos comandos da CLI:

| v3                       | v4                           |
| ------------------------ | ---------------------------- |
| `npx docus init my-docs` | `npx create-docus my-docs`   |
| `docus dev`              | `nuxt dev --extends docus`   |
| `docus build`            | `nuxt build --extends docus` |

::tip
O teu contido de Markdown existente funcionará sen cambios. A migración implica principalmente a actualización do teu fluxo de traballo de desenvolvemento e compilación.
::

## **Migrar a Docus**

Xa estás a usar unha solución baseada en Markdown para a túa documentación? Tanto se se trata de Docus v1, do modelo de documentación de Nuxt UI ou doutra solución de sitio estático, migrar a Docus é sinxelo e directo.

Docus ofrece unha solución limpa e doada de manter cunha única dependencia: a propia biblioteca de Docus. Xa non terás que xestionar varias dependencias. Todo está integrado e mantido conxuntamente, o que facilita a actualización da túa documentación.

Para migrar, simplemente mova os seus ficheiros de Markdown existentes ao cartafol `content/` do iniciador de Docus.

A partir deste punto, dous escenarios:

- **Se a túa documentación actual xa usa a sintaxe Nuxt Content e MDC,** asegúrate de que os compoñentes que usas existen en Nuxt UI. Se faltan algúns compoñentes, podes crear os teus propios facilmente.
- **Se estás a usar Markdown estándar,** podes copiar os teus ficheiros tal como están. Despois, mellora gradualmente a túa documentación usando os compoñentes integrados proporcionados por Nuxt UI.

Unha vez que o contido se moveu á carpeta content/, podes personalizar a aplicación seguindo a **documentación de configuración**.

Docus está deseñado para centrarse na redacción de contidos, polo que se xa estás a usar Markdown, podes cambiar facilmente a Docus.
