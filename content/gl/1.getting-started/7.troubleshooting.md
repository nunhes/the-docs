## Problemas con `pnpm`

Se atopas erros durante a compilación ou o desenvolvemento con `pnpm`, especialmente os relacionados coa dependencia `better-sqlite3`, pode que teñas que aprobar certos paquetes antes de que se poidan compilar.

Executa o seguinte comando para aprobar os paquetes que se van compilar:

```bash [Terminal]
pnpm approve-builds
```

Cando se lle solicite, seleccione `better-sqlite3` e `sharp` da lista de paquetes para aprobalos para a compilación.

### Activar o *shameful hoisting* (modo de compatibilidade)

Se ves erros como `Non se pode resolver 'tailwindcss'` ou `Non se pode resolver '@nuxt/ui'`, non é necesario importalos. Podes aplicar unha estrutura plana aos `node_modules` (como ocorre con npm ou yarn).

Podes activar o modo de compatibilidade creando un ficheiro `.npmrc` que conteña:

```js
shamefully-hoist=true
```
