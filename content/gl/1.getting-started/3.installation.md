## CLI `create-docus`

::steps
### Crea o teu cartafol de documentación

Usa o comando CLI `create-docus` para crear un novo proxecto Docus:

```bash [Terminal]
npx create-docus meus-docs
```

Podes escoller entre dous modelos:

- `default`: Configuración básica de Docus para documentación monolingüe
- `i18n`: Inclúe compatibilidade coa internacionalización para documentación multilingüe

```bash [Terminal]
# Crear co modelo i18n
npx create-docus meus-docs -t i18n
```

Recomendámosche usar o xestor de paquetes `npm`.

### Inicia o teu servidor de documentación en modo de desenvolvemento

Navega ata o cartafol de documentación e inicia o teu servidor:

```bash [Terminal]
cd meus-docs
npm run dev
```

Un resumo da túa documentación estará dispoñible en <http://localhost:3000>

### Escribe a túa documentación

Vai á sección [Sintax Markdown](/gl/essentials/markdown-syntax) para aprender a redactar a túa documentación.
::

## Integración da capa de Docus

Docus v4 usa un **enfoque de capas baseado en Nuxt**. Podes ampliar a capa de Docus directamente no teu ficheiro `nuxt.config.ts` con `extends: ['docus']`:

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  extends: ['docus']
})
```
