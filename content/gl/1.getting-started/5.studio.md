O módulo **Nuxt Studio** é unha interface baseada en navegador que che permite editar o teu sitio de contido de Nuxt directamente en produción. Accede a el a través de GitHub, GitLab ou a autenticación de Google no teu sitio despregado e comeza a xestionar o teu contido sen ferramentas de desenvolvemento local.

::tip{to="https://nuxt.studio/introduction"}
Consulta a documentación de Nuxt Studio para saber como instalar o módulo.
::

:video{controls loop src="https://res.cloudinary.com/nuxt/video/upload/v1767647099/studio/studio-demo_eiofld.mp4"}

O **editor Studio** permíteche xestionar completamente o teu contido desde o teu navegador no teu sitio en directo. Non hai necesidade de ferramentas de desenvolvemento local, comandos Git ou acceso ao terminal. Isto é ideal para os equipos de contido que queren editar e previsualizar os seus cambios nun ambiente familiar.

## Edición visual en directo para o teu sitio de contido Nuxt

Nuxt Studio ofrece **edición visual en directo** para sitios con tecnoloxía Nuxt Content.

Ofrecido orixinalmente como unha plataforma premium independente, Studio é agora un **módulo Nuxt gratuíto, de código aberto e autoaloxable**. Permite que todo o teu equipo, desde desenvolvedores ata editores non técnicos, cree e actualice contido de forma segura sen saír do teu sitio en directo.

## Características actuais

### ✨ **Editor visual TipTap**

Editor de Markdown mellorado con compatibilidade total cos compoñentes MDC.

### 💻 **Editor de código Mónaco**

Editor de código avanzado para ficheiros Markdown (MDC), YAML e JSON se queres editar código bruto.

### 📝 **Editor baseado en formularios**

Edita ficheiros YAML, JSON e frontmatter usando formularios xerados automaticamente baseados en esquemas de colección.

### 🎨 **Editor de props (accesorios) de compoñentes Vue**

Interface visual para editar os props dos compoñentes de Vue directamente desde o editor.

### 🔄 **Vista previa en tempo real**

Vista previa instantánea dos cambios de contido no teu sitio web en directo.

### 🔐 **Autenticación multiprovedor**

Autenticación OAuth segura con GitHub, GitLab e Google.

### 🔑 **Autenticación personalizada**

Utilidades para implementar fluxos de autenticación personalizados (contrasinal, SSO, LDAP, etc.).

### 📝 **Xestión de arquivos**

Crear, editar, renomear e eliminar ficheiros de contido no cartafol `content/`.

### 🖼 **Xestión de meios**

Biblioteca multimedia centralizada con soporte para JPEG, PNG, GIF, WebP, AVIF, SVG e outros formatos.

### 🌳 **Integración con Git**

Confirma os cambios de contido directamente desde a produción e aproveita a túa canle de CI/CD para implementalos.

### 🚀 **Modo de desenvolvemento**

Edita contido e ficheiros multimedia directamente desde o teu sistema de ficheiros local a través da interface de Studio.

### 🌍 **Internacionalización**

Compatibilidade total co i18n para 17 idiomas: AR, BG, DE, EN, ES, FA, FI, FR, ID, IT, JA, NL, PL, PT-BR, UA, ZH, ZH-TW.
