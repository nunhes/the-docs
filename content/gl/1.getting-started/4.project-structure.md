## Estrutura xeral

Docus é unha **capa de Nuxt** que amplía a túa aplicación estándar de Nuxt con funcións de documentación. Isto ofréceche a flexibilidade dun proxecto clásico de Nuxt.

Cando creas un novo proxecto de Docus con `npx create-docus meus-docs`, esta é a estrutura básica:

```bash
meus-docs/
├── content/             # O teu contido de Markdown
│   ├── index.md         # Páxina de inicio
│   └── docs/            # Páxinas de documentación
├── public/              # Recursos estáticos
└── package.json         # Dependencias e scripts
```

Aínda podes usar calquera funcionalidade ou ficheiro dun proxecto clásico de Nuxt:

```bash
meus-docs/
├── nuxt.config.ts       # Configuración de Nuxt (engadindo módulos, compoñentes...)
├── app/                 # Directorio da aplicación
    ├── app.config.ts    # Configuración da aplicación
│   ├── components/      # Compoñentes (engade os teus propios compoñentes)
│   ├── layouts/         # Maquetacións (engade as túas propias maquetacións)
│   └── pages/           # Páxinas (engade as túas propias páxinas)
└── server/              # Código do lado do servidor (engade o teu propio código do lado do servidor)
```

### Cartafol `content/`

Aquí é onde escribes as túas páxinas en Markdown. Docus xera automaticamente rutas baseadas na estrutura dos teus ficheiros.

**Estrutura monolingüe:**

```bash
content/
├── index.md              # Páxina de inicio (/)
├── getting-started.md    # Páxina de documentación (/getting-started)
└── guide/
    ├── introduction.md   # Páxina de documentación (/guide/introduction)
    └── configuration.md  # Páxina de documentación (/guide/configuration)
```

::tip
Podes separar os teus ficheiros de documentación nun subcartafol `docs/` para facelos accesibles para a ruta `/docs`. Ademais, tes a flexibilidade de substituír a túa páxina de inicio usando páxinas Vue personalizadas se o desexas. Máis información na [documentación de publicación](https://docus.dev/concepts/edition).
::

**Estrutura multilingüe (con i18n) :**

```bash
content/
├── en/
│   ├── index.md             # Páxina de inicio en inglés (/en)
│   └── guide/
│       └── introduction.md  # Páxina de documentación (/en/guide/introduction)
└── gl/
    ├── index.md             # Páxina de inicio en galego (/gl)
    └── guide/
        └── introduction.md  # Page de documentation (/gl/guide/introduction)
```

::tip{to="https://docus.dev/concepts/internationalization"}
Máis información sobre o i18n está dispoñible na sección de internacionalización.
::

### Cartafol `public/`

Os ficheiros do directorio `public/` sérvense no directorio raíz e non se modifican durante o proceso de compilación. Aquí é onde podes colocar as túas imaxes, iconas e outros recursos estáticos.

### `package.json`

Este ficheiro contén todas as dependencias e scripts para a túa aplicación. O `package.json` dunha aplicación Docus é moi minimalista e ten este aspecto:

```json [package.json]
{
  "name": "my-docs",
  "scripts": {
    "build": "nuxt build --extends docus",
    "dev": "nuxt dev --extends docus",
  },
  "dependencies": {
    "docus": "latest",
    "better-sqlite3": "^12.2.0",
    "nuxt": "^4.0.0"
  }
}
```

### `nuxt.config.ts`

*Este ficheiro non é necesario para iniciar unha aplicación Docus.*

Podes engadir módulos adicionais ao teu ficheiro de configuración de Nuxt:

```typescript [nuxt.config.ts]
export default defineNuxtConfig({
  extends: ['@vercel/analytics/nuxt/module']
})
```

### `app.config.ts`

*Este ficheiro non é necesario para iniciar unha aplicación Docus.*

::warning
Debe existir un ficheiro `nuxt.config.ts` para anular a configuración da túa aplicación. Sen o ficheiro de configuración de Nuxt, as anulacións non se aplicarán.
::

Aquí é onde podes configurar Docus para que se adapte á túa marca, xestionar o SEO, definir a túa configuración rexional e personalizar ligazóns e redes sociais. Consulta a [documentación de configuración](https://docus.dev/concepts/configuration) para obter máis detalles.

```ts [app.config.ts]
export default defineAppConfig({
  docus: {
    locale: 'gl', // Define a túa localización monolingüe
  },
  seo: {
    title: 'A miña documentación',
    description: 'A miña superdocumentación',
  },
  // ... outras configuracións
})
```

## Estrutura completa dun proxecto Nuxt

Dado que Docus é unha capa Nuxt, podes usar **calquera funcionalidade** dun proxecto Nuxt estándar:

::warning
Debe existir un ficheiro `nuxt.config.ts` para anular a aplicación Nuxt. Sen o ficheiro de configuración de Nuxt, non se aplicarán as anulacións.
::

```bash
meus-docs/
├── app/                 # Directorio da aplicación (opcional)
│   ├── app.config.ts    # Configuración da aplicación
│   ├── components/      # Compoñentes de Vue personalizados
│   ├── layouts/         # Maquetacións personalizadas
│   ├── pages/           # Páxinas de visualización personalizadas (ademais do contido)
│   ├── composables/     # Vista de elementos compoñíbeis
│   └── middleware/      # Middleware de rutas
├── server/              # Código do lado do servidor
│   └── api/             # Rutas API
├── plugins/             # Plugins Nuxt
├── middleware/          # Middleware global
└── modules/             # Modulos Nuxt personalizados
```

::tip{to="https://docus.dev/concepts/nuxt"}
Esta abordaxe baseada en capas ofrece todas as características dun proxecto clásico de Nuxt.
::
