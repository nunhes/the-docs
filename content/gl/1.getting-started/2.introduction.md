Benvido a **Docus**, unha solución de documentación totalmente integrada creada con [Nuxt UI](https://ui.nuxt.com).

## Que é Docus? ?

Docus é un tema baseado no [modelo de documentación da interface de usuario](https://docs-template.nuxt.dev/). O estilo visual está listo para usar; a túa prioridade debería ser escribir contido usando a sintaxe de Markdown e [MDC](https://content.nuxt.com/docs/files/markdown#mdc-syntax) proporcionado por [Nuxt Content](https://content.nuxt.com).

## Características principais

Este tema inclúe moitas características para mellorar a xestión da documentación:

- **Desenvolvido por** **[Nuxt 4](https://nuxt.com)** : Emprega o marco de traballo Nuxt máis recente para un rendemento óptimo.
- **Construído con** **[Nuxt UI](https://ui.nuxt.com)**: Inclúe un conxunto completo de compoñentes de interface de usuario.
- **[Sintaxe MDC](https://content.nuxt.com/usage/markdown)** **vía** **[Nuxt Content](https://content.nuxt.com)** : Admite Markdown con integración de compoñentes para contido dinámico.
- **[Nuxt Studio](https://content.nuxt.com/docs/studio)** **Compatible**: Escribe e edita o teu contido visualmente. Non se requiren coñecementos de Markdown!

- **Navegación lateral xerada automaticamente**: Xera automaticamente a navegación baseada na estrutura do contido.

- **Busca de texto completo**: Funcionalidade de busca integrada para descubrir contido.

- **Tipografía optimizada**: Tipografía refinada para unha mellor lexibilidade.

- **Modo escuro**: Admite o modo escuro segundo as preferencias do usuario.

- **Funcións ampliadas**: Explora o tema para descubrir todas as súas capacidades.
